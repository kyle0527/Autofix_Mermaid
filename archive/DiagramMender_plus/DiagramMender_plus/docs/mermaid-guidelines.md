# Mermaid 語法規範

以下列出撰寫 Mermaid 圖表時建議遵循的十條規範，以提高可讀性並避免解析錯誤。

1. **指定圖表類型與方向**：第一行必須宣告圖表類型，例如 `flowchart LR`、`sequenceDiagram`，並給予方向或初始設定。
2. **節點 ID 必須唯一**：每個節點應使用僅含英數與底線的識別字，避免重複或包含空白。
3. **節點文字需以括號或引號包覆**：如 `A[開始]` 或 `node("文字")`，確保標籤正確顯示。
4. **邊線使用正確箭頭語法**：透過 `-->`、`---` 等連線，必要時可加上文字 `A -- 說明 --> B`。
5. **子圖以 `subgraph`/`end` 包覆**：建立群組時需配對使用 `subgraph` 與 `end`，並可加上群組標題。
6. **以 `%%` 撰寫註解**：任何說明或排除的內容使用 `%%` 置於行首，避免干擾渲染。
7. **維持一致的縮排**：雖非語法要求，但建議使用兩或四個空白縮排以呈現層級，提升可讀性。
8. **避免在圖表內嵌程式碼**：Mermaid 僅支援圖表描述，不應直接放入其他語言的語法或符號。
9. **使用標準方向縮寫**：流程圖可使用 `LR`、`RL`、`TB`、`BT` 指定方向，應避免自訂或拼寫錯誤。
10. **文件中以 ```mermaid 區塊包覆**：在 Markdown 等文件引用時，使用三重反引號與 `mermaid` 語言標記確保語法高亮。

遵循上述規範有助於確保 DiagramMender 與 Mermaid 本身皆能正確解析與渲染圖表。
