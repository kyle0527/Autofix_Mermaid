# AutoFix Mermaid C4 模型

> 版本：2025-09-24 | 作者：Architecture Working Group

本文以 C4 方法論描述 AutoFix Mermaid 的高階架構，對應 `docs/architecture.md` 中的重整藍圖。

## 1. 系統脈絡圖（Context）

```mermaid
C4Context
	title AutoFix Mermaid System Context

	Person(user, "產品使用者", "透過瀏覽器或封裝桌面版本生成 Mermaid 圖表")
	Person_Ext(contributor, "規則/AI 維護者", "維護 RulePack、PromptPack 與 Engine 套件")

	System(autofix, "AutoFix Mermaid 平台", "事件驅動的程式碼→Mermaid 自動化服務")

	System_Ext(treeSitter, "Tree-sitter Grammars", "由上游提供的語法模組 (WASM)")
	System_Ext(openAI, "AI Provider", "外部提示/修復服務（可選）")
	System_Ext(repo, "Source Repositories", "使用者匯入的程式碼倉庫 / ZIP")

	Rel(user, autofix, "上傳程式碼 / 調整設定", "HTTPS / CustomEvent")
	Rel(contributor, repo, "提交規則與核心程式碼", "Git / PR")
	Rel(autofix, treeSitter, "載入語法樹解析器", "WASM")
	Rel(autofix, openAI, "選用 AI 修復", "HTTPS API")
	Rel(repo, autofix, "匯入樣本 / 規則", "Notebook / CLI")
```

## 2. 核心容器圖（Container）

```mermaid
C4Container
	title AutoFix Mermaid Container Diagram

	Person(user, "產品使用者")

	Container_Boundary(webapp, "AutoFix Mermaid Web App") {
		Container(ui, "UI Shell", "ESM / Vanilla JS", "呈現控制面板、訂閱 EventBus DOM event")
		Container(moduleWorker, "ESM Worker", "Worker module", "執行解析/規則引擎、透過事件回報結果")
	}

	Container(eventBus, "Event Bus", "純 JS Util", "跨模組事件交換中心，對 DOM 廣播")
	Container(pipeline, "Processing Pipeline", "AsyncProcessingPipeline", "佇列化任務、統計、錯誤隔離")
	Container(errorMgr, "ErrorPropagationManager", "Error Context Core", "追蹤錯誤鏈與恢復策略")
	Container(memoryMgr, "MemoryManager", "Resource Guard", "量測與回收資源")

	Container(coreEngine, "DiagramMender Core", "TypeScript", "解析 AST → 建構 IR → 產出 Mermaid")
	Container(rulePacks, "Rule / Prompt Packs", "JSON Manifest", "自動修復與樣板設定")

	System_Ext(treeSitter, "Tree-sitter WASM", "語言解析模組")
	System_Ext(aiProvider, "AI Provider", "選用 AI 修復服務")

	Rel(user, ui, "操作、檢視輸出", "DOM Events")
	Rel(ui, eventBus, "訂閱/發布", "CustomEvent autofix:event")
	Rel(ui, moduleWorker, "postMessage", "StructuredClone")

	Rel(moduleWorker, pipeline, "enqueue job", "PipelineFactory")
	Rel(pipeline, eventBus, "publish", "PipelineEvents")
	Rel(pipeline, errorMgr, "propagate failure", "ErrorContext")
	Rel(errorMgr, eventBus, "broadcast recovery", "ErrorEvents")
	Rel(pipeline, memoryMgr, "量測/清理", "Memory snapshot")

	Rel(moduleWorker, coreEngine, "解析與生成", "IR / Mermaid")
	Rel(coreEngine, rulePacks, "載入規則", "JSON manifest")
	Rel(coreEngine, treeSitter, "載入語法", "WASM")
	Rel(coreEngine, aiProvider, "Fallback AI", "HTTPS")
```
