# Legacy Assets

This folder stores deprecated UI prototypes and historical documents that should no longer be loaded by the main application.

## Structure

- `archive/` – Stub files that point to archived copies of project documentation.
- `archives/` – Versioned backups of changelogs, guides, and PR notes.
- `ui-prototype/` – The retired UI experiments (`UI-clean.js`, `worker-clean.js`, `work.html`).

All content here is preserved for reference only; production builds must not import files from this directory.
