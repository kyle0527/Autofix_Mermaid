### 🚨 **問題 1: Tree-sitter WASM 載入完全失效**

#### **技術細節**
```javascript
// 錯誤位置：js/engine/tree-sitter-loader.js:386
Error: TreeSitter.Language.load not available
    at TreeSitterLoader._validateInitialization
```

#### **根本原因分析**
1. **WASM 模組路徑問題**: Tree-sitter WASM 檔案可能未正確載入
2. **環境依賴缺失**: Node.js 環境下 Tree-sitter 模組不可用
3. **初始化順序錯誤**: WASM 模組在語言載入前未完成初始化

#### **影響範圍**
- ✅ **正常運作**: 正則表達式解析器 (備用機制)
- ❌ **完全失效**: 所有 Tree-sitter 功能
- ❌ **嚴重影響**: JavaScript/TypeScript 精準解析
- ❌ **完全中斷**: Python 高精度分析

#### **修復策略**
```javascript
// 建議修復方案
class TreeSitterLoader {
  async initialize() {
    try {
      // 1. 檢查 WASM 支援
      if (typeof WebAssembly === 'undefined') {
        throw new Error('WebAssembly not supported');
      }
      
      // 2. 載入 Tree-sitter 核心模組
      const TreeSitter = await import('tree-sitter');
      
      // 3. 初始化 WASM 模組

      // 4. 驗證功能可用性

        throw new Error('TreeSitter.Language.load not available');
      }
      
      this.TreeSitter = TreeSitter;
      this.isInitialized = true;
    } catch (error) {
      // 優雅降級到正則表達式解析
      console.warn('Tree-sitter initialization failed, using fallback');
      this.useMinimalFallback = true;
    }
  }
}
```

### 🚨 **問題 2: 語言解析器 API 不一致**

#### **技術細節**
```javascript
// 錯誤位置：js/engine/tree-sitter-loader.js:633
Error: Unsupported language: function test() { return 42; }
```

#### **錯誤分析**
```javascript
// 當前錯誤的實作
async loadLanguage(codeContent) {  // ❌ 錯誤：傳入程式碼內容
  return await this._doLoadLanguage(codeContent);
}

// 正確的實作應該是
async loadLanguage(languageName) {  // ✅ 正確：傳入語言名稱
  return await this._doLoadLanguage(languageName);
}
```

#### **API 調用錯誤鏈**
1. `parse(code)` → `getParser(code)` → `loadLanguage(code)` ❌
2. 應該是：`parse(code, language)` → `getParser(language)` → `loadLanguage(language)` ✅

#### **修復方案**
```javascript
class TreeSitterLoader {
  async parse(code, language = 'javascript') {
    const parser = await this.getParser(language);
    return parser.parse(code);
  }
  
  async getParser(language) {
    if (!this.parsers[language]) {
      await this.loadLanguage(language);
      this.parsers[language] = new this.TreeSitter.Parser();
      this.parsers[language].setLanguage(this.languages[language]);
    }
    return this.parsers[language];
  }
}
```

```javascript
  }
```

```javascript
async analyzeMultiLanguageProject(projectPath) {
  const jsResult = await this.analyzeJavaScript(projectPath);
  const pyResult = await this.analyzePython(projectPath);

```

#### **修復方案**
```javascript
async analyzeMultiLanguageProject(projectPath) {
  const jsResult = await this.analyzeJavaScript(projectPath);
  const pyResult = await this.analyzePython(projectPath);
  
  // ✅ 修正：加入安全檢查
  const jsLanguages = jsResult?.metadata?.languages || ['javascript'];
  const pyLanguages = pyResult?.metadata?.languages || ['python'];
  
  const combinedResult = this.combineResults(jsResult, pyResult);
  
  // 補充後設資料
  combinedResult.metadata = {
    languages: [...jsLanguages, ...pyLanguages],
    totalFiles: (jsResult?.statistics?.filesProcessed || 0) + 
                (pyResult?.statistics?.filesProcessed || 0),
    analysisTime: Date.now()
  };
  
  return combinedResult;
}
```
