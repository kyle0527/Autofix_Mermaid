
# @diagrammender/cli (v0.3.0)

This CLI integrates AutoFix Mermaid v3.7 improvements into DiagramMender.

## Usage

```bash
npx diagrammender --help
npx diagrammender scan ./your-project
npx diagrammender file ./path/to/file.py --kind flowchart --links
```

## Highlights
- Multi-language detection (Python/JS/TS/Java/Go/…)
- Rich pipeline (parsers → analyzers → emitters → composer)
- High-quality Mermaid output with compatibility fixes
- Trace mode for diagnostics
